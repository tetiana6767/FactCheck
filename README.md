# FactCheck — AI Agents for Digital Trust

Проєкт мультиагентної системи для аналізу новин і перевірки тверджень за допомогою зовнішніх доказів. Архітектура передбачає вебінтерфейс, API на FastAPI та оркестрацію агентів із LangGraph.

FastAPI приймає текст, виділяє декларативні твердження, шукає точні збіги в локальному навчальному корпусі та повертає простежуваний знімок доказів. Вебклієнт окремо показує мовні сигнали, статус мовної моделі та зв'язок між тезою, цитатою і джерелом. Поточна версія ще не виконує зовнішній вебпошук і завжди повертає статус про недостатність доказів для фактологічного висновку.

Етап 3 додає строгий адаптер OpenRouter, локальну Pydantic-валідацію структурованої відповіді та контрольний класифікатор TF-IDF + Logistic Regression. Класифікатор призначений для майбутнього навчання й експериментального порівняння на розміченій вибірці; він не визначає фактичний вердикт без такого навчання.

Етап 4 додає керований мультиагентний граф із сімома спеціалізованими ролями, спільним незмінним знімком доказів, частковими відмовами та пояснюваною інтегральною оцінкою. Часті прості ролі використовують Mistral Small 3.2 або Qwen3.5 9B, аналіз доказів і скептик — DeepSeek V4.1 Flash, а рідкісні верифікатор та арбітр — GPT-4o-mini. Повний GPT-4o не використовується.

Політика `economy` пропускає невиправдані модельні виклики, а `research` запускає всі ролі для майбутнього контрольного експерименту. Сумарний бюджет зупиняє наступні ролі після досягнення налаштованої межі. Вебінтерфейс показує виконані рольові оцінки, пропущені ролі, токени, витрати, покриття доказами й узгодженість.

## Вимоги

- Python 3.13.
- Віртуальне середовище `venv`.

## Локальний запуск

```cmd
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r apps\api\requirements.txt
cd apps\api
..\..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Після запуску вебклієнт доступний за адресою `http://127.0.0.1:8000`, перевірка стану API — `http://127.0.0.1:8000/api/health`, документація OpenAPI — `http://127.0.0.1:8000/docs`.

Для увімкнення OpenRouter задайте ключ та ідентифікатор сумісної зі structured outputs моделі у змінних середовища. Не зберігайте ключ у коді або Git:

```cmd
set OPENROUTER_API_KEY=ваш_ключ
set OPENROUTER_MODEL_DEFAULT=openai/gpt-4o-mini
```

Без цих значень API продовжує працювати в безпечному локальному режимі та повертає статус `not_configured`.

Повний перелік рольових змінних і безпечні значення за замовчуванням наведено у файлі [`.env.example`](.env.example). Шаблон не містить секретів.

Запити додатково обмежені ціною провайдера: не більше `$0.15/M` вхідних і `$0.60/M` вихідних токенів. Для тимчасових відмов OpenRouter отримує впорядкований список основної та резервної моделей; цінова межа поширюється на весь маршрут.

З'єднання перевірено через OpenRouter із DeepSeek V4.1 Flash: структурована відповідь проходить локальну Pydantic-валідацію. Telemetry звіту містить фактичну модель, токени, затримку та вартість, яку повернув провайдер.

Приклад запиту:

```json
{
  "claim": "Київ — столиця України."
}
```

Відповідь містить початковий текст, список `claims`, сумісне поле `evidence` та версійований `evidence_snapshot`. URI з префіксом `urn:factcheck:test-corpus:` позначають навчальні записи й не є зовнішніми вебджерелами.

## Тести

```cmd
.venv\Scripts\python.exe -m pip install -r apps\api\requirements-dev.txt
cd apps\api
..\..\.venv\Scripts\python.exe -m pytest -q
```

## Структура

- `apps/web/` — вебінтерфейс, стилі та JavaScript-клієнт API.
- `apps/api/app/api/` — HTTP-маршрути.
- `apps/api/app/config/` — типізована конфігурація й реєстр рольових моделей.
- `apps/api/app/graph/` — незмінний стан, економна політика та LangGraph-каркас.
- `apps/api/app/agents/` — граф і агенти аналізу.
- `apps/api/app/services/` — виділення тверджень, мовний аналіз, пошукові й модельні адаптери, реєстр доказів та координація перевірки.
- `apps/api/app/ml/` — контрольні моделі машинного навчання у стилі scikit-learn.
- `apps/api/app/schemas/` — схеми запитів і відповідей.
- `apps/api/app/storage/` — зберігання історії.
- `apps/api/tests/` — тести API та його компонентів.
- `data/` — приклади й набори даних для оцінювання.
- `models/` — локальні моделі за потреби.
- `docs/` — документація проєкту.
